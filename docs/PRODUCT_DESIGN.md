# Product Design

## 产品命题

ResearchGraph 服务单个研究者从“读过”到“理解、连接、判断”的过程。核心对象不是 PDF 文件，而是经过用户整理的 `Structured Paper`。

## 信息架构

1. **Dashboard**：当前研究态势与下一步入口。
2. **Literature Library**：论文 CRUD、搜索和筛选。
3. **Paper Detail**：结构化知识与个人判断的主要编辑面。
4. **Knowledge Graph**：跨论文的方法、问题、概念、数据与想法关系。
5. **My Research**：研究方向作为分析边界。
6. **Research Agent**：证据检索与未来分析入口。

## 设计语言

以“研究手稿 / 编辑台”为视觉方向：暖白纸张背景、深墨色、苔绿色、少量锈红，Georgia 衬线标题配简洁无衬线正文。避免 KPI 驱动的商业 SaaS 感，强调信息密度、安静层级和可读性。

## 关键交互

- 文献卡优先展示标题、作者、年份、venue、标签、一句话总结与阅读状态。
- 图谱节点按类型区分视觉，但文字永远可见；图谱支持类型筛选、搜索、缩放和节点详情。
- 手工关系必须填写 evidence，并显式选择 created_by；AI 关系始终保留独立 provenance。
- Agent 无证据时直接说明缺失，不用模型常识填空。

## 可访问性与响应式

语义化表单、键盘焦点、明确 label、减少动画偏好；窄屏改为底部导航，内容和表单退化为单列，图谱保持触摸可用。
